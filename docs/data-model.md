# Data model (Cloud Firestore)

Source of truth: Zod schemas in `shared/schemas/` (types are inferred from
them), collection names in `shared/firestore-paths.ts`, access in
`firebase/firestore.rules`, indexes in `firebase/firestore.indexes.json`.

## Conventions

- **IDs** — per-user documents use the Firebase Auth `uid`; `favourites` use
  `{userId}_{productId}`; reference data uses natural keys (category value,
  atoll code, island slug); everything else uses auto-generated ids. The id is
  **not** stored inside the document.
- **Timestamps** — `createdAt` on every document, `updatedAt` on mutable ones,
  always server time (rules require `request.time`). Read as `Date`.
- **Ownership fields** — `farmerId`, `consumerId`, `userId`, `reporterId`,
  `actorId` hold uids.
- **Money** — integer **laari** (1 MVR = 100 laari) in `*Laari` fields.
- **Phones** — E.164, `+960` + 7 digits.
- **Text in two languages** — `{ en: string, dv?: string }`; at least one non-empty (Dhivehi-only allowed; `en` may be "").
- **Writers** — _client_ = browser/mobile SDK, enforced by Security Rules;
  _server_ = Admin SDK in trusted server code or admin scripts only.

## Relationships and denormalisation

- `products.location` copies `farmerProfiles.location`, and
  `products.farmerVisible` copies "farm is approved and visible". Rules check
  both on every farmer write; the server re-syncs `farmerVisible` whenever an
  admin approves, rejects, blocks or unblocks a farmer.
- `farmerProfiles.deliveryDestinations` summarises the farmer's
  `deliveryAreas` for filtering; services should update both together.
- `users.role` mirrors the custom claim for display and admin queries; the
  claim is the only thing used for authorization.

## Storage layout

| Path                                     | Read          | Write                                                                                  |
| ---------------------------------------- | ------------- | -------------------------------------------------------------------------------------- |
| `products/{farmerId}/{productId}/{file}` | public        | owning active farmer; jpeg/png/webp ≤ 5 MB; `imagePaths` must point inside this folder |
| `farmers/{farmerId}/{file}`              | public        | owning active farmer; jpeg/png/webp ≤ 5 MB                                             |
| `payments/{farmerId}/{paymentId}/{file}` | farmer, admin | owning active farmer; image or PDF ≤ 5 MB; new files only (no overwrite)               |
| `branding/{file}`                        | public        | server only                                                                            |
